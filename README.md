# 云命 YunMing · 生辰排盘

输入出生年月日时，一键出完整排盘 + 大白话解读。本地运行，纯离线，数据不联网。

界面风格沿自「云梯 CloudLadder」框架（经典深灰 · 蓝主题）。

> 非生产级软件；命理为传统民俗推演，仅供娱乐参考，不构成任何决策建议。

## 普通用户：直接拿现成的用

进 [`发布/`](发布/) 目录，有三种装法，选一个就行：

| 文件 | 怎么用 | 适合 |
|---|---|---|
| `云命-桌面版/` | 双击文件夹里 `云命.exe` 直接跑 | 最轻，免安装 |
| `云命-安装包.exe` | 双击解压到目标文件夹，再跑 `云命.exe` | 想装到别处 |
| `云命-桌面版.zip` | 解压后跑 `云命.exe` | 想自己分发 |

目标电脑**无需装任何环境**——程序自带运行所需的一切。

放桌面：双击 `创建桌面快捷方式.bat`；卸载：双击 `卸载云命.bat`。
命例档案存在本机 `AppData\Roaming\yunming\data`，不上传。

## 开发者：从源码跑

需要 Node.js 环境。

```bash
npm install        # 首次装依赖
node server.js     # 纯网页版（调试）
# 或
npm start          # Electron 桌面版
```

浏览器访问 `http://127.0.0.1:8717`（网页模式）。

### 功能一览

- **四柱八字**：十神、藏干、纳音、旬空、胎元/命宫/身宫、五行统计、格局、旺衰粗判（含建禄/羊刃、食伤制杀特判）、用神喜忌、神煞（天乙/文昌/桃花/驿马/华盖/红鸾/天喜/羊刃/将星/金舆/红艳/天德/月德/孤辰寡宿）、大运十步（喜忌着色）、近三年流年
- **紫微斗数**：十二宫主星辅星、生年四化、大限、五行局、命主身主、格局
- **称骨**：年月日时骨重分列、男女命歌诀
- **八宅命卦**：东西四命、吉凶方位
- **择日黄历**：建除十二神、黄黑道、宜忌、冲煞、吉凶神、喜财福神方位、二十八宿
- **大白话报告**：十章节全口语化解读，可复制 / 导出 TXT

### 历法口径

- 八字年柱以**立春**为界；紫微四化按**农历年**起；称骨按**农历年**计——口径不同会在「附：历法说明」自动注明
- 八字引擎经 lunar-javascript 与 iztro 双库交叉验证，六个已知命例回归通过
